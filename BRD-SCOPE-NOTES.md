# BRD Scope Notes for Client Demo

This Version 2 demonstration implements the approved Phase 1 requirements described in Sections 1–35 of the BRD.

The QA gap items on the final BRD page are recommendations for later client discussion and are not represented as approved Phase 1 commitments:

- Dedicated Staff Attendance module
- Tax / GST calculation module
- Sale Cancellation / Refund approval workflow
- Damaged/Expired Stock Write-off workflow
- Year-on-Year comparison report
- Explicit global-vs-business role-scope policy beyond the business-access controls demonstrated here

The demo does include Fuel Rate History because it directly improves the Petrol Pump client demonstration and reporting.

Production implementation still requires a secured backend/database, password hashing, server-side access control, deployment configuration, production printer testing and opening-balance migration. The present build is intentionally a LocalStorage-based clickable demo as requested.
